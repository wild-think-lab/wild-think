### 一句话定义

**Python 是一门解释型、跨平台的通用编程语言：写完不用编译，交给解释器逐行执行。**

对比一下就直观了：

| 语言 | 特点 | 典型用途 |
| --- | --- | --- |
| Python | 语法接近自然语言，生态极全 | 脚本、数据分析、AI、运维自动化、Web 后端 |
| C | 极快，但要自己管理内存 | 操作系统、驱动、高性能库底层 |
| Shell | 天然适合"调用命令" | 服务器日常运维 |
| Java/Go | 工程规范强，适合大型服务 | 企业级后端 |

### 它擅长的三件事

1. **把重复劳动写成脚本**：批量改文件、定时抓数据、自动发报表。
2. **处理数据**：读表格、算统计、画图，几行代码。
3. **快速做原型**：想法验证比写生产代码快得多。

### 它不擅长的

- 极致性能（那部分交给 C/Go，或用现成的库）。
- 大型团队强约束的工程（没有编译期检查，类型靠注解和工具补）。

> 一个常被忽略的点：Python 的优势不在语言本身多巧妙，而在**第三方库的数量**。你想做的事，九成有人已经写好了。

### 为什么适合零基础

- 语法里没有 `{ }`、没有 `;`，靠**缩进**表示层级，读起来像在写大纲。
- 报错信息直接告诉你哪一行、什么问题。
- 不用先学"编译、链接"这套流程，写完立刻能跑。

### 先看一段真实的代码

```python
# 读一个文本文件，统计每个词出现次数，打印前 5 名
from collections import Counter

words = open("notes.txt", encoding="utf-8").read().split()
for word, count in Counter(words).most_common(5):
    print(f"{word}: {count}")
```

这段代码用到文件读取、循环、f-string、标准库——后面 7 章讲的正是这些东西。现在只需要看懂"它在做一件有用的事"，不必理解每个符号。

### 本章小结

- Python = 解释执行 + 生态庞大，适合脚本、数据、自动化。
- 它的强项是"快速把想法变成能跑的东西"。
- 学它的顺序永远是：能跑起来 → 会写小脚本 → 会拆函数 → 会管依赖。

### IP 地址 = 网络号 + 主机号

一个 IPv4 地址是 4 段数字，`192.168.1.10`。它被拆成两部分：

- **网络号**：标识"在哪个网络里"。
- **主机号**：标识"网络里的哪台机器"。

怎么拆，由**子网掩码**决定。`255.255.255.0` 意思是前 24 位是网络号，写作 `/24`。

```text
192.168.1.10 /24
├─ 网络 192.168.1.0
└─ 主机部分 .10
```

### 三个必须记住的概念

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| 网段 | 同一网络号下的所有地址 | `192.168.1.0/24` |
| 网关 | 出这个网段要走的那台设备（路由器） | `192.168.1.1` |
| 广播地址 | 网段最后一个地址，不能给机器用 | `192.168.1.255` |

同网段的两台机器通信**不需要网关**，直接发；跨网段必须交给网关转发。这就是"我 ping 不通隔壁网段"时首先要查网关的原因。

### 私网地址：你在家用的都是这一类

| 段 | 说明 |
| --- | --- |
| `10.0.0.0/8` | 大内网，公司常用 |
| `172.16.0.0/12` | 云厂商内网常见 |
| `192.168.0.0/16` | 家用路由器 |
| `127.0.0.1` | 本机回环，永远指向自己 |

私网地址不能直接出现在公网上，需要 NAT 转换。所以：

- 你家里机器是 `192.168.x.x`，但公网访问用的是宽带出口 IP。
- 云服务器给的是公网 IP（或经 NAT 的地址），和内网 IP 是两回事。

### CIDR 怎么快速算

`/24` = 256 个地址，可用 254 个（去掉网络地址和广播地址）。

规律：`/n` 的地址数 = 2^(32-n)。

| 掩码 | CIDR | 地址数 | 可用主机 |
| --- | --- | --- | --- |
| 255.255.255.0 | /24 | 256 | 254 |
| 255.255.255.128 | /25 | 128 | 126 |
| 255.255.255.192 | /26 | 64 | 62 |
| 255.255.0.0 | /16 | 65536 | 65534 |

### 判断"是否同网段"（手算方法）

两台机器 `192.168.1.10/24` 与 `192.168.2.20/24`：

1. 各自网络号：`192.168.1.0` 与 `192.168.2.0`。
2. 不同 → **跨网段**，必须经网关。

同网段只需看掩码覆盖的那几位是否相同。

### 查看自己的网络

```bash
ip a              # 所有网卡的地址和掩码
ip route          # 默认网关是哪台（default via ...）
ip route get 8.8.8.8   # 去某个地址实际走哪条路由
```

Windows 对应 `ipconfig`。

### 自己验证

```bash
ip a | grep inet
ping -c 2 网关IP          # 通说明本网段链路正常
ping -c 2 8.8.8.8         # 通说明能出网
ping -c 2 baidu.com       # 通说明 DNS 也正常
```

三条 ping 分别验证"本网段""出网""DNS"，这是最省时间的拆分方式。

### 本章小结

- IP = 网络号 + 主机号，怎么分由掩码决定。
- 同网段直连，跨网段走网关。
- `/24` 有 254 个可用地址。
- 排错先 ping 网关，再 ping 公网 IP，最后 ping 域名。

### 为什么需要 NAT

```
私网地址（192.168/10/172.16）不能直接上公网
→ 出口设备把源地址换成公网 IP
```

**NAT 的本质**：改包头的地址/端口，并维护一张映射表。

### 三种 NAT

```
SNAT（源地址转换）：内网出去上网
DNAT（目的地址转换）：外部访问内网服务（端口映射）
MASQUERADE：动态出口 IP 时用（如拨号上网）
```

```bash
# iptables 例子
iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -o eth0 -j MASQUERADE
iptables -t nat -A PREROUTING -p tcp --dport 8080 -j DNAT --to-destination 192.168.1.10:80
```

### 端口映射（外部访问内网）

```
外部 IP:8080 → 内网 192.168.1.10:80
```

**四个必要条件**：

```
① 内网服务监听 0.0.0.0（不是 127.0.0.1）
② 内网主机防火墙放行
③ 出口设备有 DNAT 规则
④ 出口有固定公网 IP（或 DDNS）
```

**"外面访问不到"** 缺任何一条都不通。

### 四种"外面访问不到内网服务"

**① 服务只听 127.0.0.1**

```bash
ss -lntp | grep 8080
```

**② 主机防火墙**

```
firewall-cmd --list-ports
```

**③ NAT 没配/配错方向**

```
DNAT 要在 PREROUTING（不是 POSTROUTING）
```

**④ 运营商封端口**

```
家宽常封 80/443/25 → 用非标端口或备案
```

### 家宽没有固定 IP 怎么办

```
① DDNS（动态域名）
② 反向隧道（frp / cloudflared）—— 最省事
③ 云服务器做跳板（WireGuard 打通）
```

**"直接暴露公网"** 有风险（扫描机器人几分钟就来了）。

### 一个安全的家庭/小办公出口

```
① 出口做 NAT，不直接暴露内网
② 需要远程访问 → VPN/WireGuard 或反向隧道
③ 只映射必要端口（且有认证）
④ 定期看"谁在尝试登录"
```

### 检查清单

```
□ 清楚私网/公网/出口设备
□ 知道 SNAT/DNAT 的区别与方向
□ 端口映射四要素齐全
□ 服务监听 0.0.0.0
□ 主机防火墙已放行
□ 无固定 IP 时有 DDNS/隧道方案
□ 不直接暴露管理端口
□ 有"外网可达性"的外部验证（不只在本地测）
```

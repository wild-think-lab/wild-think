### 三个基本概念

```
频段：2.4G（穿墙好、干扰多）/ 5G（快、覆盖小）/ 6G（Wi-Fi 6E）
信道：2.4G 只有 1/6/11 互不重叠；5G 信道多
带宽：20/40/80/160MHz（越宽越快，但干扰更大）
```

**"信道都挤在 1"** → 邻居互相干扰（实际吞吐掉一半）。

### 信号满格但不快：五个原因

**① 信道拥挤**

```
2.4G 用户多 → 空口竞争严重
→ 换 5G 或换信道（用 WiFi Analyzer 看）
```

**② 老设备拖慢整体**

```
一个 802.11n 设备接入 → 速率协商下降
```

**③ 上行带宽被占满**

```
测速只测下行 → 上行 20M 被备份/上传占满
```

**④ AP 回程是有线的还是有线的？**

```
无线中继（mesh 无线回程）→ 带宽减半
```

**⑤ 数量太多：AP 太少**

```
一台家用路由带 40 个设备 → 空口排队
```

### 认证与安全

```
WPA2-PSK  → 家用够用
WPA3      → 更安全（部分老设备不支持）
WPA2-Enterprise（802.1X）→ 办公/企业
```

**"公司 Wi-Fi 一个密码所有人"** → 无法追溯谁在干什么（企业要用 802.1X + 账号）。

### 办公网的三件套

```
① AP 统一管理（AC/云管理）
② 802.1X 认证（账号/证书）
③ 访客网络隔离（VLAN + 只出公网）
```

**"访客和办公同一个网段"** → 访客能扫内网。

### 覆盖规划

```
① 先测再布（不要按"感觉"放 AP）
② 办公区每 1–2 个房间一个 AP（5G）
③ 走廊/会议室重点覆盖
④ 避免"AP 互相听到但都很弱"（会互相降速）
```

### 排障三件套

```bash
# Linux 上看无线
iw dev
iw dev wlan0 link
nmcli device wifi list

# Windows
netsh wlan show interfaces
netsh wlan show networks mode=bssid
```

**判据**：

```
信号强度 -50dBm 好，-70dBm 一般，-80dBm 差
速率 / 信道 / 重传率 → 才说明"空口质量"
```

### 检查清单

```
□ 主要设备在 5G（2.4G 留给 IoT）
□ 2.4G 只用 1/6/11
□ AP 数量与人数匹配
□ 办公用 802.1X
□ 访客网络隔离
□ 有覆盖热图/实测
□ 无线回程尽量少（优先有线）
□ 有"谁在占带宽"的可视化
□ 关键设备（打印机/IoT）单独 SSID
```

### 先记住一句话

**Linux 是操作系统内核，它会调硬件；你在屏幕上敲的命令，走的是另一批程序。**

日常说的"装个 Linux"，其实装的是"内核 + 一堆工具"的整套组合，这套组合叫**发行版（distribution）**。

### 内核、发行版、Shell，三层关系

| 层 | 是什么 | 举例 | 你平时会碰它吗 |
| --- | --- | --- | --- |
| 内核 kernel | 唯一能直接指挥 CPU、内存、磁盘、网卡的代码 | Linux kernel | 很少直接碰，只通过命令间接使用 |
| 发行版 | 内核 + 软件包管理器 + 默认配置打包成的整套系统 | Ubuntu、Debian、Rocky、openEuler | 装机器时选的就是它 |
| Shell | 解释你敲的命令并把结果还给你的程序 | bash、zsh | 天天碰，登录后就在用 |

发行版之间的差别，主要在**包管理器**和**默认配置**。命令本身九成是通用的，所以学会一套，换发行版不至于从零开始。

> 常见选择：想要教程多、资料全就 Ubuntu；想要和公司服务器一致，多半是 Rocky / 麒麟 / openEuler 这类企业发行版。

### 为什么服务器偏爱 Linux

- **不花钱且可改**：源码开放，出问题能查到最底层。
- **省资源**：一台 1 核 1G 的机器也能跑起完整服务，图形界面那套开销全省了。
- **稳定且能远程**：核心操作全在命令行里，一根 SSH 连接就能管几千公里外的机器。
- **一切皆文件**：配置、设备、日志都是文件，能用同一套命令读写。

### 命令行不是"高级操作"，是默认操作

图形界面是给人看的，命令行是给"可重复的操作"用的。同样装一个 Web 服务器：

```bash
# 图形界面：点下载、点下一步、选目录、勾选项……四台机器就要点四遍
# 命令行：一行，四台机器跑同一行
sudo apt install -y nginx
```

命令行的价值不在"显得专业"，在于**能记录、能重复、能批量**。这也是这门课后面所有内容的前提。

### 自己验证一下

在任何一台 Linux 机器（或稍后第 2 章装好的虚拟机）上执行：

```bash
uname -r          # 内核版本
cat /etc/os-release   # 发行版名字和版本
echo $SHELL       # 当前用的 Shell
```

三条命令分别回答"内核是什么、系统是哪个、我在用什么 Shell"。看不懂输出没关系，先记住这三条命令各查什么。

### 本章小结

- Linux = 内核，装系统装的其实是发行版。
- 发行版差别主要在包管理器和默认配置。
- Shell 是你和系统之间的翻译，命令行是服务器上的主要工作方式。

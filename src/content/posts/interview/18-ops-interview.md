### 一、一台机器 CPU 100%，你怎么查

**及格**：top → 看哪个进程 → 再看是用户态还是内核态。

**加分**：

```
① 先分"是计算还是等待"（us vs sy vs wa）
② 用户态高：perf top / pprof / 火焰图
③ 内核态高：syscall 密集（上下文切换/软中断）
④ 单核 100% 多核闲：绑核/单线程瓶颈
⑤ 确认"是不是预期"（压测还是故障）
```

**面试官在听**：你有没有"先分类再说方法"的习惯。

### 二、内存一直涨，怎么定位

```
① 确认是"进程"还是"缓存"（available vs free）
② 进程 RSS 趋势（缓慢上涨 = 泄漏）
③ 语言级分析（Go pprof heap / Java heap dump）
④ 排除"堆外"（DirectBuffer/元空间/线程栈）
⑤ 容器场景看 cgroup 的 memory.current
```

**"只说重启"** 是减分的。

### 三、磁盘满了怎么处理

```
① df / df -i（空间 vs inode）
② 找"谁在占"（du 逐层、lsof +L1 找已删除文件）
③ 区分"业务数据"与"日志/临时"
④ 清理要留证据（先记录，再删）
⑤ 长期：日志轮转 + 配额 + 独立分区
```

**"直接 rm"** 可能删掉未释放的文件（空间不降）。

### 四、服务 502，你的排查顺序

```
① 502 是谁返回的（LB/网关/后端）
② 网关日志看 upstream 错误类型
   connection refused → 后端没监听
   timeout → 后端慢/连接池满
   reset → 后端主动断开
③ 后端侧看监听、连接数、慢请求
④ 抓包定论（握手/RST/无响应）
```

**"先问'谁返回的 502'"** 是高手的第一句。

### 五、上线后错误率升高，怎么止损

```
① 先判断"是否本次变更引起"（时间相关性 + 版本标签）
② 止损优先：回滚/切流量/降级开关
③ 保留现场：日志/快照/指标
④ 再定位根因
```

**"先止损再排查"** 是 SRE 的第一原则。

### 六、怎么做容量规划

```
① 有基线：当前 QPS/延迟/资源占用
② 有增长：业务预期（不是猜）
③ 有瓶颈：压测找到"最先到顶"的资源
④ 有冗余：峰值 × 1.5–2
⑤ 有验证：扩容后压测复核
```

**"拍脑袋加机器"** 会被追问"依据是什么"。

### 七、怎么设计告警才不吵

```
① 告警要"可行动"（每条都有处置动作）
② 分级（P0 电话/P1 IM/P2 日报）
③ 合并（同一根因聚合）
④ 阈值基于"用户感知"（SLO），不是"资源百分比"
⑤ 定期清理（长期没人处理的告警要下线）
```

### 八、灰度发布怎么做判定

```
① 指标带版本标签（能对比）
② 判据：错误率、P99、业务指标
③ 分档推进（1% → 20% → 100%），每档观察窗口
④ 自动回滚阈值
⑤ 数据库变更要"向前兼容"
```

**"灰度发了没看指标"** = 白做。

### 九、怎么保证"发布不中断服务"

```
① readiness 探针能反映真实可服务
② 优雅退出（preStop + grace period）
③ 滚动策略（maxUnavailable 小）
④ 双版本兼容（接口/数据）
⑤ 有回滚路径（且演练过）
```

### 十、数据备份怎么才算"有"

```
① 有 RPO/RTO
② 3-2-1（3 份/2 介质/1 异地）
③ 定期恢复演练（唯一验收标准）
④ 备份监控（大小/执行/空间）
⑤ 备份与生产隔离（防勒索）
```

**"备份成功但没恢复过"** 不算有备份。

### 十一、一次故障后你怎么复盘

```
① 时间线（分钟级）
② 根因（技术 + 流程）
③ 影响面（用户/时长/数据）
④ 整改项（owner + 截止日）
⑤ 可复用的 runbook/监控
```

**"复盘变成追责会"** 是组织问题（对事不对人）。

### 十二、你怎么看"要不要上 K8s"

```
① 看服务形态（无状态/有状态）
② 看团队能力（能不能运维）
③ 看规模与变更频率
④ 看成本（人力 > 机器）
⑤ 小规模单体可能更划算
```

**"能说'不该上'的理由"** 比"什么都能上"更成熟。

### 面试官真正在听的

```
① 你有没有"分层/分类"的思维
② 你能不能"用证据定论"（而不是猜）
③ 你知不知道"止损优先"
④ 你说的每个动作是否"可执行"
```

**"每句话都落到命令/判据"** 是最强的表达方式。

### 检查清单（自测）

```
□ 每道题都能说"先分类，再方法"
□ 能给出具体命令
□ 知道止损与定位的先后
□ 有容量与备份的量化概念
□ 能说"什么时候不该做"
□ 复盘能落到整改闭环
```

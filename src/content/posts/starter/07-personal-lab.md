### 三档配置

| 档位 | 硬件 | 能跑什么 |
| --- | --- | --- |
| 入门 | 16G 内存笔记本 | 2–3 台 VM、单节点 K8s、Docker |
| 标准 | 32G 内存 + 1T SSD | 3 节点 K8s、Ceph 三节点、Prometheus |
| 接近生产 | 64G + 独显/多网卡 | 多集群、GPU 实验、虚拟网络设备 |

**关键不是 CPU 而是内存**。K8s 三节点实测：每节点 4G 起（含系统），加监控与存储后要 6–8G。

### 网络规划

先定一个网段，避免与家里路由器冲突：

```
宿主机/物理网络：  192.168.1.0/24（路由器）
实验网段：        10.10.0.0/24

10.10.0.1   网关（软路由/NAT）
10.10.0.10  控制节点
10.10.0.11  工作节点1
10.10.0.12  工作节点2
10.10.0.20  存储节点
10.10.0.100-200  LoadBalancer（MetalLB 池）
```

**别用 192.168.0.x**：很多家庭路由器占用，容易冲突。

### 虚拟化方案

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| VMware Workstation | 稳定、快照好用 | 收费（个人免费版功能受限） |
| VirtualBox | 免费 | 性能一般，网络配置略麻烦 |
| Hyper-V | Windows 原生、性能好 | 与 VMware 冲突 |
| Proxmox VE（裸机） | 接近生产、Web 管理 | 需要一台独立机器 |
| KVM + libvirt（Linux 宿主机） | 性能最好、灵活 | 需要命令行功底 |

**推荐路径**：Windows 笔记本用 VMware/Hyper-V 起步；有一台闲置机器就装 PVE。

### 资源分配（32G 宿主机实例）

```
宿主机系统：      4G
控制节点（VM）：  6G / 4 核 / 40G 盘
工作节点1：       8G / 4 核 / 60G 盘
工作节点2：       8G / 4 核 / 60G 盘
留余量：          6G
```

**永远留 15% 余量**：宿主机自己卡死时，所有 VM 一起卡死。

CPU 不要"全给"：VM 的 vCPU 总数不超过物理核数（不含超线程）。

### 磁盘策略

```
① 系统盘用 SSD，别用机械盘（K8s 的 etcd 对 IO 敏感）
② 用精简置备（thin provision），但注意空间不会自动回收
③ 快照只留 1–2 个，多了严重影响性能
④ Ceph 实验至少三块独立盘（或三个独立虚拟盘）
```

**在同一个物理盘上做"三副本 Ceph"没有任何可靠性意义**，只能用来练流程。

### 常见"跑不动"的原因

| 现象 | 原因 |
| --- | --- |
| 创建 VM 后宿主机极卡 | 内存超卖（总和 > 物理） |
| K8s 节点 NotReady | 磁盘空间不足（kubelet 有阈值） |
| etcd 报慢 | 磁盘 IO 抖动（机械盘或宿主机在跑大任务） |
| 网络不通 | 虚拟网卡模式错（NAT vs 桥接） |
| 快照后极慢 | 快照链太长 |

### 网络模式的坑

| 模式 | 适用 | 问题 |
| --- | --- | --- |
| NAT | 单机实验，能上网 | 外部访问需端口转发；VM 之间可通 |
| 桥接 | 希望 VM 像独立机器 | 需要路由器有足够 IP；公司网络可能限制 |
| 仅主机（Host-only） | 纯内网实验 | 不能上网，需要自己做 NAT |

**做 K8s 集群实验推荐**：一块 NAT 网卡（上网）+ 一块 Host-only/桥接（集群内网）。

### 电费与噪音（现实问题）

一台常开的塔式服务器（双路、机械盘阵列）：

```
功耗约 120–200W → 每月约 90–140 度电 → 约 50–80 元
噪音：机箱风扇持续 40–50 分贝，放卧室不现实
```

**折中方案**：

- 用笔记本/迷你主机（NUC、零刻）做长期实验环境，功耗 15–40W，几乎无声。
- 塔式机器只在做重实验时开机。
- 云服务器按需开（用完销毁），比常开硬件更省心。

### 备份实验环境

```
① VM 快照（做完关键步骤前打一个）
② 导出 OVF/OVA 存到移动硬盘
③ 配置与脚本放 Git（重建时靠脚本而不是靠记忆）
```

**"能重建"比"能备份"更重要**：一个仓库里放好安装脚本，环境坏了半天就能重来。

### 一个可行的一年计划

```
第 1 月：装虚拟化，跑通 3 台 Linux + 静态网络
第 2 月：Docker + Compose，跑几个常用服务
第 3 月：kubeadm 三节点集群 + 一个业务
第 4 月：监控（Prometheus + Grafana + 告警）
第 5 月：CI/CD（GitLab + Runner）打通发布
第 6 月：存储（NFS/iSCSI/Ceph）实验
第 7 月：网络（VLAN、路由、抓包排障）
第 8 月：安全（堡垒机、WAF、扫描）
第 9 月：高可用（Keepalived、数据库主从）
第 10 月：故障演练（拔盘、断网、杀进程）
第 11 月：性能压测与调优
第 12 月：把全流程写成文档，形成自己的"手册"
```

### 检查清单

```
□ 网段规划好，不与家庭网络冲突
□ 宿主机内存留 15% 余量
□ 系统盘是 SSD
□ 有"重建脚本"在 Git 里
□ 快照不超过 2 个
□ 电费与噪音在可接受范围
```

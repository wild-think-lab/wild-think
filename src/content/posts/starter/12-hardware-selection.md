### 先定用途，再定配置

```
① 跑虚拟化/容器实验（Proxmox）：核心多 + 内存大
② NAS/备份：盘位多 + 稳定
③ AI 推理：显卡 + 显存
④ 生产小集群（3 节点）：稳定 + 网络
```

**"先买再想用途"** 是浪费的开始。

### CPU：看四个维度

```
① 核心数（虚拟化/并发）
② 单核性能（编译/数据库）
③ 平台代数（新平台 = 省电 + 更多内存通道）
④ 是否有核显（没显卡时能不能点亮）
```

**家用/实验室**：

```
E5 洋垃圾：便宜多核，但功耗高、单核弱、平台老
锐龙/酷睿新平台：单核强、省电、内存通道好
```

**"要跑 20 个容器"** → 内存比 CPU 更先到顶。

### 内存：宁可多，不要刚好

```
虚拟化：宿主机 8G + 每个 VM 2–4G
容器：按"峰值 × 1.5"
```

**ECC 的取舍**：

```
家用/实验：非 ECC 可以接受（便宜、平台多）
长期跑数据/ZFS：ECC 强烈建议（ZFS 对内存错误敏感）
```

### 硬盘：分层

```
① 系统盘：SSD（小容量即可）
② 数据盘：HDD（容量）
③ 缓存/数据库：NVMe（IOPS）
④ 备份盘：独立介质（甚至离线）
```

**"全用 HDD 跑数据库"** 是性能灾难；**"全用 NVMe 存冷数据"** 是浪费。

### 网卡

```
1GbE：家用够
2.5GbE：NAS/内网传输甜点
10GbE：多节点集群/存储网络
```

**"多节点跑 Ceph"** → 至少要 10GbE（否则重建慢到怀疑人生）。

### 电源与散热

```
① 电源留 30% 余量（尤其是多盘启动）
② 80Plus 金牌以上（长期电费）
③ 机箱风道（多盘要前置风扇）
④ 噪音：家用要考虑（服务器风扇很吵）
```

**"12 盘位机箱 + 500W 电源"** 开机瞬间可能起不来（盘启动电流）。

### 五个"买了才发现不合适"

**① 主板 SATA 口不够**

```
要 8 盘但主板 4 个 SATA → 加扩展卡（注意 PCIe 通道）
```

**② 内存插槽少**

```
4 槽插满 4×16G = 64G，想升 128G 只能换条
```

**③ ITX 机箱装不下扩展卡**

```
想加 10GbE/显卡 → 空间与散热都不够
```

**④ 洋垃圾平台没 IPMI**

```
远程管理只能靠系统内软件（挂了就没法救）
```

**⑤ 硬盘型号混用**

```
不同批次/不同转速混在 RAID → 性能与寿命都受影响
```

### 一个"实验/家用"的推荐配置

```
CPU：锐龙 5/7 或 至强 E-2300（有核显）
内存：32–64G（虚拟化起步）
系统盘：512G NVMe
数据盘：2–4 块 HDD（可做 ZFS mirror/RAID1）
网卡：板载 2.5G
电源：550–650W 金牌
机箱：能装 4–8 盘，前置风扇
```

### 一个"小集群（3 节点）"的推荐

```
每节点：8 核 / 32G / 256G SSD + 1T SSD / 双口 10GbE
交换机：10GbE（至少 4 口）
UPS：至少给"断电保存"留 10 分钟
```

### 检查清单

```
□ 用途先定（虚拟化/NAS/AI/集群）
□ CPU 核心与单核都评估
□ 内存留升级空间（槽位/单条容量）
□ 盘分层（系统/数据/缓存/备份）
□ 有独立备份介质
□ 网卡与用途匹配（集群要 10G）
□ 电源留余量（多盘启动）
□ 散热与噪音可接受
□ 有远程管理（IPMI 或至少带外）
□ 有 UPS（重要数据）
□ 硬盘型号统一（RAID 内）
```

### 无线与有线的本质差别

```
有线：独占介质，问题通常是"带宽/丢包"
无线：共享介质（同一信道上的所有设备竞争），问题通常是"干扰/竞争/漫游"
```

**"信号强"只说明发射功率够，不代表能跑得快**：干扰、信道拥塞、认证方式都会拖慢。

### 四个最常见的坑

**① 信道重叠**

2.4G 只有 1/6/11 三个互不重叠的信道。如果三个 AP 都用信道 6，就会互相干扰。

```
2.4G 信道宽度 20MHz 时，1/6/11 互不重叠
5G 信道多得多（且 80MHz 带宽可用），优先用 5G
```

**② 2.4G 拥挤**

微波炉、蓝牙、无线鼠标、邻居 WiFi 都在 2.4G。办公区应**把 2.4G 只留给 IoT 设备，终端优先连 5G**。

**③ 漫游不切换**

设备粘在"信号弱但连得上"的 AP 上，不切换到更近的 AP。

```
原因：设备自己决定何时漫游（通常信号低于 -75dBm 才考虑）
解决：AP 侧开启 802.11k/v/r（辅助漫游），并降低 AP 发射功率让覆盖更"密"
```

**反直觉**：**AP 发射功率越大，漫游越差**（设备能连到很远的 AP，就不切换）。办公区应"多 AP + 低功率"。

**④ 认证方式拖慢**

```
WPA2-PSK：兼容性好
WPA2/WPA3 混合：部分老设备不支持
802.1X（EAP-TLS）：企业首选，但需要证书
```

Portal 认证（网页登录）会导致"连上了但上不了网"，且掉线后要重新登录。

### 三侧排查

**① 终端（手机/笔记本）**

```bash
# Linux
nmcli dev wifi list                    # 周围 AP、信号、信道
iwconfig wlan0                          # 当前连接信息
cat /proc/net/wireless                  # 信号质量
iw dev wlan0 link                       # 详细链路（含速率）
```

输出关键字段：

```
signal level: -55 dBm       # > -60 好，-60~-70 中，< -75 差
bit rate: 866 Mb/s          # 实际协商速率
```

Windows：

```powershell
netsh wlan show interfaces
netsh wlan show networks mode=bssid   # 看周围 AP 与信道
```

**② AP 侧**

```
- 信道占用（是否有邻居 AP 在同一信道）
- 关联客户端数与流量
- 是否有"客户端反复重连"（认证问题）
```

**③ 网络侧**

```bash
# 从无线网段测试到网关、到外网
ping -c 20 10.0.0.1        # 看丢包与延迟抖动
mtr -n 10.0.0.1            # 分段延迟
```

无线丢包的特征：**延迟抖动大**（如 5ms / 120ms / 8ms 交替），而不是稳定高延迟。

### 判断流程

```
① 信号强度多少？（-55 好，-75 差）
② 协商速率多少？（低 → 信道/干扰问题）
③ ping 网关丢包率？（高 → 无线链路问题）
④ 同一 AP 上其他设备快不快？（都慢 → AP/回程问题）
⑤ 换到 5G 是否改善？（是 → 2.4G 干扰）
```

### 速率与带宽的对应

| 协议 | 理论速率 | 实际（一对一） |
| --- | --- | --- |
| 802.11n（2.4G，40MHz） | 300Mbps | 60–100Mbps |
| 802.11ac（5G，80MHz） | 866Mbps | 300–500Mbps |
| 802.11ax（WiFi6，80MHz） | 1200Mbps | 500–800Mbps |

**"我家千兆宽带但 WiFi 只有 200Mbps"** 是正常的：无线实际速率通常是标称的一半不到。

### 办公无线设计要点

```
① 覆盖设计：按"每个 AP 覆盖 30–50 平米（办公区）"估算
② 信道规划：2.4G 只用 1/6/11，相邻 AP 错开
③ 功率控制：中低功率，避免"远距离粘连"
④ 回程：AP 用有线回程（PoE），不要无线回程（会砍半带宽）
⑤ 认证：企业用 802.1X，访客用独立 SSID + Portal
⑥ 隔离：访客网络与内网 VLAN 隔离
```

**访客网络必须隔离**：访客设备不打补丁，是内网横向移动的常见入口。

### 无线安全

```
① 禁用 WEP/WPA（只用 WPA2-Enterprise 或 WPA3）
② 关闭 WPS（有已知攻击）
③ 管理界面不暴露到无线网段
④ 定期审计：是否有"员工自建的热点"（最常见的内网漏洞）
```

**"员工插个便携路由器"是办公网的安全盲区**：它会把无线流量桥到内网，绕过所有边界控制。

### 检查清单

```
□ 2.4G 只用 1/6/11，相邻 AP 错开
□ 5G 优先，2.4G 留给 IoT
□ AP 功率中等，覆盖密而非远
□ 开启 802.11k/v/r 辅助漫游
□ AP 有线回程（PoE）
□ 访客网络独立 VLAN 且隔离
□ 禁用 WPS
□ 定期扫"自建热点"
□ 有无线使用率与关联数监控
```

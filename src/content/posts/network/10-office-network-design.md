### 先规划地址

一个 200 人的办公网，建议按"角色 + 楼栋"划分：

```
192.168.0.0/22  总地址段（1022 个可用地址）

按 VLAN：
VLAN 10  192.168.0.0/24   办公（有线）
VLAN 20  192.168.1.0/24   无线（员工）
VLAN 30  192.168.2.0/25   访客（隔离）
VLAN 40  192.168.2.128/26 服务器/打印机
VLAN 50  192.168.2.192/27 网络管理（交换机/IPMI）
```

原则：

1. **每个 VLAN 不超过 /24**：广播域越小越稳。
2. **管理网单独**：交换机、IPMI、AP 的管理地址放在独立 VLAN，与业务隔离。
3. **访客严格隔离**：只允许出向互联网，禁止访问内网任何地址。
4. **留出增长空间**：/22 还能再切 4 个 /24。

### 三层网络结构

```
Internet → 出口路由器/防火墙 → 核心交换机（三层） → 接入交换机 → 终端
                                        ↓
                                    服务器区
```

- **核心交换机**做三层（VLANIF/SVI），不要在路由器上做所有 VLAN 间路由。
- **接入交换机**只做二层，接终端。
- 汇聚层在 200 人规模可以省掉（核心直连接入）。

### 无线：AC + AP 的关键参数

| 参数 | 建议 |
| --- | --- |
| 频段 | 2.4G 与 5G 双频，**5G 为主** |
| 信道 | 2.4G 只用 1/6/11；5G 用非重叠信道 |
| 功率 | 相邻 AP 功率错开，避免同信道干扰 |
| 覆盖 | 每个 AP 覆盖 200–400 平米（开放办公） |
| 容量 | 一个 AP 同时约 30–50 个活跃终端 |

**"网慢"最常见的无线原因**：

1. 2.4G 信道重叠（三个 AP 都用信道 6）。
2. AP 密度不够，终端在弱信号下反复重连。
3. 单 AP 接入 80 个终端，超出容量。

排查工具：看 AP 的关联数与信道利用率（很多 AC 自带）。

### 准入与认证

三种常见方案：

| 方案 | 适用 | 代价 |
| --- | --- | --- |
| WPA2-PSK 统一密码 | 小办公室（<20 人） | 人员流动要改密码 |
| WPA2-Enterprise（RADIUS） | 有域环境 | 需要 NPS/FreeRADIUS |
| Portal 认证（网页登录） | 访客、外包 | 体验差，但可控 |

有 AD 域的公司，用 NPS 做 802.1X 是最优解：

```
AP → RADIUS（NPS）→ AD 校验 → 下发 VLAN
```

好处：员工用域账号自动登录，离职能立刻禁用。

### 出口与冗余

```
主线路（电信）─┐
              ├─ 出口路由（策略路由/主备）→ 防火墙 → 核心
备线路（联通）─┘
```

三种冗余方式：

| 方式 | 切换时间 | 成本 |
| --- | --- | --- |
| 主备（一条备用） | 秒级（需要健康检查） | 低 |
| 双活（两条都用） | 无感（按策略分流） | 中 |
| 多线 BGP | 无感 | 高 |

中小企业常见做法：主备 + 基于 ping/HTTP 的健康检查，切换 10 秒内。

**别忘了 DNS**：主备 DNS（一个内网、一个公网），否则 DNS 挂了全网"上不了网"。

### "网慢"的五层排查

```
① 终端层：是不是只有一台慢？（换设备/换网线验证）
② 无线层：信号强度、信道、关联数
③ 接入层：交换机端口是否有 CRC 错误、是否协商成百兆
④ 核心/出口：带宽是否跑满、是否有广播风暴
⑤ 应用层：是不是某个网站/服务本身慢（换目标测试）
```

每层的判断依据：

```bash
# ③ 交换机上看端口错误
show interface gi0/1        # 看 input errors / CRC
# ④ 看出口带宽
# ⑤ 换目标：ping 网关 vs ping 8.8.8.8 vs curl 某网站
```

**CRC 错误增长**通常是网线/水晶头/端口问题，换线换口即可，不要先怀疑"网络设备不行"。

### 五个常见设计错误

1. **所有设备一个 VLAN**：广播风暴会全网瘫，且无法做任何隔离。
2. **管理口暴露在办公网**：交换机/IPMI 被扫到就是大事故。
3. **无线与有线同一网段**：无法区分策略，访客能访问内网。
4. **没有 DHCP 租约规划**：地址池用尽，新设备拿不到 IP（表现为"连上 WiFi 但不能上网"）。
5. **没有网络文档**：机柜图、IP 规划、VLAN 表全在某个人的脑子里。

### 必须留的文档

```
□ 拓扑图（含出口、核心、接入、AP 位置）
□ IP 与 VLAN 规划表
□ 机柜与端口对照表（哪个口接哪台设备）
□ 设备清单（型号、位置、保修到期）
□ 变更记录
```

没有这些，一次人员变动就会让网络变成黑盒。

### 一句话总结

办公网的设计优先级是：**地址与 VLAN 规划 → 管理与隔离 → 无线容量 → 出口冗余 → 文档**。前两项做对，后面出问题的概率会小一个数量级。

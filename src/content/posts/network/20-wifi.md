### 先分清"卡"的四种表现

```
① 连不上（认证/关联失败）
② 连上但慢（速率低/干扰/回传带宽）
③ 时断时续（漫游/信道切换/干扰）
④ 人多就崩（AP 容量/关联数上限）
```

**"先确认是哪一种"**，否则换设备也解决不了。

### 问题一：信道规划

```
2.4G：只有 1/6/11 三个不重叠信道
5G  ：信道多，但有 DFS 信道（雷达规避）
6G  ：Wi-Fi 6E 才有
```

**"AP 全在信道 6"** 是最常见的自干扰：

```
同层多个 AP 同信道 → 互相退让 → 全部变慢
```

**检查**：

```bash
# Linux 上扫周围 AP
iw dev wlan0 scan | grep -E "SSID|channel|signal"
# 或 nmcli
nmcli dev wifi list
```

**实践**：

```
① 2.4G 只用于 IoT/老设备，主流量走 5G
② 5G 用"自动信道"但限制在非 DFS 段，或用规划好的固定信道
③ 高密度场景降低单 AP 功率（避免过度覆盖导致"连了远的 AP"）
```

### 问题二：干扰

```
① 微波炉/蓝牙/无线鼠标（2.4G）
② 邻频干扰（信道带宽 80MHz/160MHz 时更严重）
③ 同频（其他 AP）
```

**判据**：

```
信号强（-50dBm）但速率低（<100Mbps）→ 干扰/协商问题
信号弱（<-80dBm）→ 覆盖问题
```

**"信号强但慢"** 基本不是覆盖问题，而是干扰或协商失败。

### 问题三：漫游

```
现象：走动时断线几秒 / 需要手动重连
原因：客户端"粘着"信号弱的 AP 不走
```

**企业方案**：

```
① 统一 SSID + 同网段
② 802.11k/v/r（辅助漫游）
③ 控制器侧"强制漫游"（信号低于阈值踢掉）
```

**"家用路由器 + 多个 AP 同名 SSID"** 效果通常很差（没有 k/v/r）。

### 问题四：DHCP 与地址池

```
现象：能连上 Wi-Fi 但拿不到 IP / 拿不到就断
原因：DHCP 池耗尽 / DHCP 服务器不可达
```

**检查**：

```bash
# 客户端
ip a; journalctl -u NetworkManager | tail -30
# 服务器（isc-dhcp）
grep -i "no free leases" /var/log/syslog
```

**"公司年会 300 人连同一个网"** 常见就是 DHCP 池只有 254 个。

### 问题五：认证与 802.1X

```
现象：反复弹出认证 / 认证成功但无网
原因：
① 证书过期（EAP-TLS）
② RADIUS 不可达
③ VLAN 分配错误（认证后进了错网段）
```

**检查**：

```bash
# 客户端日志
journalctl -u wpa_supplicant | tail -50
# RADIUS 侧
tail -50 /var/log/freeradius/radius.log
```

**"认证成功但没网"** → 往往是 VLAN/策略问题，不是无线问题。

### 五个"看起来是无线其实是别处"的问题

**① 回传带宽不足**

```
AP 用无线回传（mesh）→ 带宽减半再减半
→ 有线回传是硬要求（高密度场景）
```

**② 上游交换机端口瓶颈**

```
AP 接千兆口，但 20 个用户同时下载 → 打满
```

**③ DNS 慢被误认为"Wi-Fi 卡"**

```
"打开网页转圈"→ 先测 ping 网关与 DNS
```

**④ 客户端省电策略**

```
笔记本 Wi-Fi 省电 → 延迟抖动大
→ 关省电或换驱动
```

**⑤ 2.4G 设备太多**

```
IoT 设备全挤 2.4G → 空口拥塞
→ 单独给 IoT 开 2.4G SSID，人用 5G
```

### 一个"排障顺序"

```
1) 连不上 → 看认证/关联日志
2) 连上无 IP → 看 DHCP
3) 有 IP 但慢 → 看信号强度/信道/干扰/回传
4) 走动断线 → 看漫游（k/v/r）
5) 人多崩 → 看 AP 关联数与空口利用率
```

### 检查清单

```
□ 2.4G/5G 分离 SSID（人走 5G）
□ 信道规划（2.4G 只用 1/6/11）
□ 高密度降功率（避免粘远 AP）
□ 有线回传（不用 mesh 做主干）
□ 开 802.11k/v/r
□ DHCP 池足够（按峰值人数 × 1.5）
□ 认证链路有监控（RADIUS 可达）
□ 有"空口利用率"监控
□ IoT 单独 SSID
□ 客户端省电策略已排查
```

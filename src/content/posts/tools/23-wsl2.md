### 装什么

```powershell
wsl --install -d Ubuntu-22.04
wsl --set-default-version 2
wsl -l -v
```

**"默认 WSL1"** 的老机器要显式设 version 2。

### 五个坑

**① 跨文件系统性能差**

```
/mnt/c/... 下读写比 ext4 慢 5–10 倍
→ 代码放 ~/（Linux 侧），不要放 /mnt/c
```

**② systemd 默认不开**

```ini
# /etc/wsl.conf
[boot]
systemd=true

[interop]
appendWindowsPath=false
```

```powershell
wsl --shutdown
```

**"想要 systemctl"** 必须开 systemd。

**③ 端口不是"localhost 共享"那么简单**

```
WSL2 里监听 localhost → Windows 侧可通过 localhost 访问（一般可以）
Windows 里服务 → WSL 访问要用 host IP（或 host.docker.internal）
```

```bash
# WSL 里访问 Windows 宿主
cat /etc/resolv.conf | grep nameserver
```

**④ 内存不自动回收**

```ini
# ~/.wslconfig (Windows 用户目录)
[wsl2]
memory=8GB
processors=4
swap=2GB
```

**"内存吃满 Windows"** → 加 memory 上限。

**⑤ 时间/时钟漂移**

```
休眠后时间不准 → 影响 TLS/日志
→ wsl --shutdown 再进，或同步 NTP
```

### 与 Docker 的关系

```
方案 A：Docker Desktop（Windows 侧，WSL2 后端）
方案 B：WSL2 里直接装 docker-ce（不依赖 Desktop）
```

**"方案 B"** 更轻（不用 Desktop 授权），但要自己管端口与卷。

### 常用配置（一次配好）

```ini
# /etc/wsl.conf
[boot]
systemd=true
[interop]
enabled=true
appendWindowsPath=false
[automount]
options="metadata,umask=22,fmask=11"
```

```ini
# %UserProfile%\.wslconfig
[wsl2]
memory=8GB
processors=4
localhostForwarding=true
```

### 开发常用

```bash
# 在 WSL 里跑服务，Windows 浏览器访问
python -m http.server 8000
# 浏览器 http://localhost:8000

# VS Code
code .        # 需要 Windows 侧装了 VS Code + Remote-WSL
```

### 检查清单

```
□ 版本是 WSL2
□ systemd 已开启（需要时）
□ 代码放在 Linux 文件系统内
□ .wslconfig 限制了内存
□ 端口访问方向明确（WSL→Win / Win→WSL）
□ 时间同步正常
□ Docker 方案选了一个（不混用）
□ 有快照/导出备份（wsl --export）
□ 有"重置"预案（wsl --unregister 会删数据）
```

### 先接受一件事：Vim 是"动词 + 对象"

```
操作 = 动词（d 删除 / c 修改 / y 复制）+ 对象（w 词 / i 内 / a 周围 / $ 行尾）
```

理解这个结构，就不用背 200 个组合：`diw`（删掉光标所在的词）、`ci"`（改引号内的内容）、`ya}`（复制到大括号结尾）。

### 20 个操作，按使用频率排

**移动（最高频）**

```
h j k l        ← ↓ ↑ →
w / b          下一个/上一个词首
0 / $          行首 / 行尾
gg / G         文件首 / 文件尾
:42            跳到第 42 行
Ctrl-d/u       半页下/上
%              跳到匹配的括号
```

**编辑**

```
i / a          插入（光标前 / 后）
o / O          下一行新开 / 上一行新开
x             删一个字符
dd            删整行
cc            改整行（= dd + i）
yy            复制整行
p / P         粘贴到后 / 前
u             撤销
Ctrl-r        重做
.             重复上一次修改 ← 最值钱的一个键
```

**选区与块操作**

```
v             字符选区
V             行选区
Ctrl-v        块选区（列编辑）
> / <         缩进 / 反缩进（选区内）
I             块选区插入（配合 Ctrl-v，批量加注释神器）
```

**搜索替换**

```
/word          向下搜（n 下一个，N 上一个）
?word          向上搜
:%s/old/new/g  全文替换
:%s/old/new/gc 全文替换并逐条确认
:noh           清除搜索高亮
```

**保存退出**

```
:w / :q / :wq / :q!
:w !sudo tee %     用 sudo 保存（改系统配置时用）
```

### 三个立刻提升效率的组合

**① `.` 重复**

改一处 → 用 `n` 跳到下一个匹配 → 按 `.` 重复。这是 Vim 的核心效率来源，比宏更常用。

**② 宏（`q` 录制）**

```
qa             开始录制到寄存器 a
...操作...
q              结束录制
@a             执行一次
10@a           执行 10 次
```

场景：给 50 行加同样的前缀/后缀，手改要 5 分钟，宏 10 秒。

**③ 块选区批量注释**

```
Ctrl-v          进入块选区
jjjj            向下选 4 行
I               进入插入
#               输入注释符
Esc             等一秒，4 行全部加上
```

### 编辑配置文件时最实用的动作

改 Nginx/SSH/systemd 配置，最常用这套：

```
/word        定位到段落
V            选中整段
y p          复制一段做备份（心里有数）
cc           整段重写
:w !sudo tee %   需要 root 时保存
.            改同结构的多行
```

**改之前先 `cp file file.bak` 或 `git diff`**，别把 sshd_config 改坏把自己锁外面。

### 三个新手坑

**① 模式搞混**

按了 `i` 想退出，按 `Esc` 后又按了 `i`……记住：**不确定自己在哪个模式时，连按两次 Esc，然后看左下角有没有 `-- INSERT --`**。

**② 粘贴缩进全乱**

在 `:set paste` 前粘贴会自动缩进。现代 Vim（8+）用 `:set paste` 或 bracketed paste（终端支持时自动生效）。临时办法：先 `:set paste`，粘完 `:set nopaste`。

**③ 搜索高亮不消失**

`:noh` 清掉。或在 `.vimrc` 加 `nnoremap <Esc> :noh<CR>`。

### 最小可用 `.vimrc`

```vim
set number relativenumber     " 相对行号，配合 5j 这种跳转
set expandtab tabstop=2 shiftwidth=2
set ignorecase smartcase      " 小写忽略大小写，含大写则精确
set incsearch hlsearch
set backspace=indent,eol,start
set noswapfile                " 避免残留 .swp
syntax on
```

不想折腾插件的话，这 8 行足够应付服务器上的所有编辑。

### 降级方案：只记 5 个键

在客户现场、临时机器上，紧张时只需要：

```
i   进入编辑
Esc 退出编辑
:wq 保存退出
dd  删行
u   撤销
```

能改完配置不把事情弄坏，比会 200 个快捷键更重要。
